# Student Attendance Management System

## 📌 Project Overview

The Student Attendance Management System is a web-based application developed using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). The system provides a simple and efficient way to manage student attendance digitally. It allows administrators to manage students, teachers to record attendance, and students to view attendance information.

---

## 🎯 Features

- User Login
- Home Page
- Admin Dashboard
- Teacher Dashboard
- Student Dashboard
- Add Student
- Update Student
- Delete Student
- View Student List
- View Teacher List
- Mark Attendance
- Save Attendance in MongoDB
- Attendance Report
- Low Attendance Alert (Basic)
- Logout
